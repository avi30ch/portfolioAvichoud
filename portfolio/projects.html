Multithreaded HTTP Server with Bandwidth Limiting

  • Built a C++17 HTTP file server using POSIX sockets, a fixed worker pool, and a bounded connection queue to serve concurrent downloads.
  • Implemented per-connection bandwidth limiting with a byte-based token bucket, monotonic-clock replenishment, and configurable transfer rates starting at 1 KiB/sec.
  • Added binary-safe transfers, partial-write handling, request timeouts, document-root validation, and automated integration checks for download integrity, concurrency, rate limits, and error responses.
